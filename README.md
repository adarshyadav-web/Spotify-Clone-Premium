# Spotify Clone Premium

A high-fidelity landing page inspired by the Spotify web experience. Featuring the iconic "Circular" typography, vibrant green accents, and a responsive glassmorphic navigation bar.

## 🚀 Features

- **Iconic Aesthetic**: Signature Spotify color palette and branding.
- **Hero Section**: High-impact design with clear call-to-action.
- **Multi-Device Support**: Optimized for Mobile, TV, Car, and Computer.
- **Modern Footer**: Professional link columns and social integrations.

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **FontAwesome**

## 📦 Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/adarshyadav-web/Spotify-Clone-Premium.git
   ```
2. Open `index.html` in your browser.
